# Library Management System — Project Proposal

## Problem
University libraries need an organized
way to manage books, borrowing, and returns.
Manual tracking can lead to errors.

## Users
- Students: Search, borrow, and return books.
- Librarians: Add, remove, and manage books.

## Scope
The system will allow students to search
for books, borrow available books, and
return borrowed books. Librarians can
manage books and view borrowing records.
